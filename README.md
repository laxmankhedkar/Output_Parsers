---

## 📌 What are Output Parsers?

An **Output Parser** is used to convert the raw response generated by an LLM into a structured and usable format.

For example, an LLM may return:

```text
Name: John
Age: 25
City: Pune
```

An output parser can convert this response into a structured Python object such as:

```python
{
    "name": "John",
    "age": 25,
    "city": "Pune"
}
```

Output parsers are useful when we need predictable and structured outputs from an LLM.

## 3. JSON Output Parser

File:

```text
json_output_parser.py
```

A JSON output parser is useful when we want the LLM to return information in a JSON format.

Example:

```json
{
    "name": "John",
    "age": 25,
    "profession": "Data Scientist"
}
```

This makes the response easier to process programmatically.

### Use cases

* API responses
* Data extraction
* Information extraction
* Structured application workflows
* LLM-based automation

---

## 4. Pydantic Output Parser

File:

```text
pydantic_output_parser.py
```

Pydantic can be used to define a structured schema for the expected LLM response.

Example:

```python
class Person(BaseModel):
    name: str
    age: int
    profession: str
```

The model output can then be validated against the defined structure.

### Benefits

* Structured data
* Type validation
* Predictable output
* Easier integration with Python applications

---

## 5. Structured Output Parser

File:

```text
structured_output_parser.py
```

This example demonstrates how to generate structured information from an LLM instead of relying only on free-form text.

Structured outputs are particularly useful when an application needs specific fields from the model response.

# ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/laxmankhedkar/Output_Parsers.git
```

### 2. Navigate to the project

```bash
cd Output_Parsers
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

For macOS/Linux:

```bash
source venv/bin/activate
```


# 💡 Why Output Parsers Matter

LLMs normally generate free-form text.

However, real applications often need predictable data.

For example:

```text
LLM Response
     ↓
Output Parser
     ↓
Structured Data
     ↓
Python Application
```

This makes it easier to connect LLMs with:

* APIs
* Databases
* Web applications
* RAG pipelines
* Data processing systems
* Automation workflows
